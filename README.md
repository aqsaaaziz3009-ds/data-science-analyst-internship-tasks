# Data Science & Analytics Internship Tasks

This repository contains multiple tasks completed as part of the **Data Science & Analytics Internship**.  
The purpose of these tasks is to demonstrate practical skills in data analysis, data visualization, and machine learning using Python.

Each task focuses on solving a real-world problem and follows a structured data science workflow including data loading, data cleaning, exploratory data analysis (EDA), model building, and evaluation.

---

## 🔹 Tasks Overview

### **Task 1: Exploring and Visualizing the Iris Dataset**
- Performed Exploratory Data Analysis (EDA) on the Iris dataset.
- Analyzed feature distributions and relationships between variables.
- Used visualizations such as histograms, box plots, scatter plots, and pair plots.
- Identified key features useful for species classification.

📁 File: `Task1_Iris_EDA.ipynb`

---

### **Task 2: Credit Risk Prediction**
- Built a classification model to predict loan approval outcomes.
- Handled missing values and encoded categorical variables.
- Visualized important financial features.
- Evaluated model performance using accuracy and confusion matrix.

📁 File: `Task2_Credit_Risk_Prediction.ipynb`

---

### **Task 3: Customer Churn Prediction (Bank Customers)**
- Analyzed customer behavior to predict churn.
- Cleaned and prepared the dataset.
- Trained a classification model to identify customers likely to leave the bank.
- Identified key churn factors through data analysis.

📁 File: `Task3_Customer_Churn_Prediction.ipynb`

---

### **Task 4: Predicting Insurance Claim Amounts**
- Applied regression techniques to predict medical insurance charges.
- Explored relationships between personal attributes and insurance costs.
- Trained a Linear Regression model.
- Evaluated the model using MAE and RMSE.

📁 File: `Task4_Insurance_Regression.ipynb`

---

### **Task 5: Personal Loan Acceptance Prediction**
- Predicted whether customers will accept a personal loan offer.
- Performed data preprocessing, encoding, and feature scaling.
- Trained a Logistic Regression model.
- Evaluated performance using accuracy score and confusion matrix.

📁 File: `Task5_Personal_Loan.ipynb`
