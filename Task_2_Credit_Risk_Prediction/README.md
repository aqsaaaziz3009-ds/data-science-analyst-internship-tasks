## **Task 2: Credit Risk Prediction**

### **Objective**
The objective of this task is to predict whether a loan applicant is likely to default on a loan based on their financial and personal information. This task focuses on data cleaning, exploratory analysis, and building a classification model.

---

### **Dataset**
The dataset used for this task is the **Loan Prediction Dataset** obtained from Kaggle.

**Dataset Details:**
- Features include applicant income, loan amount, education, credit history, and marital status.
- Target Variable:
  - Loan Status (Approved / Not Approved)

---

### **Libraries Used**
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Scikit-learn  

---

### **Task Workflow**

#### **1. Data Loading**
- The dataset is loaded using Pandas.
- Data is stored in a DataFrame for analysis.

#### **2. Data Cleaning**
- Missing values are identified and handled appropriately.
- Categorical variables are encoded into numeric format.

#### **3. Exploratory Data Analysis**
- Visualized key features such as loan amount, income, and education.
- Analyzed relationships between features and loan approval.

#### **4. Model Training**
- A classification model (Logistic Regression / Decision Tree) is trained.

#### **5. Model Evaluation**
- Model performance is evaluated using accuracy score and confusion matrix.

---

### **Key Insights**
- Credit history plays a major role in loan approval.
- Applicant income and loan amount significantly affect credit risk.
