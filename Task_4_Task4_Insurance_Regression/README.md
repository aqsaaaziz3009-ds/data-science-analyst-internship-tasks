Task 4: Predicting Insurance Claim Amounts

📌 Objective
The objective of this task is to predict medical insurance claim amounts based on personal and health-related features using a regression model.

📊 Dataset
Name: Medical Cost Personal Dataset
Number of Samples: 1,338

Features:
Age
Sex
BMI
Number of Children
Smoking Status
Region

Target Variable:
Charges (Medical Insurance Cost)

🛠️ Tools & Libraries Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn

🔍 Steps Performed
Loaded the dataset and explored its structure
Checked for missing values and data types
Converted categorical variables into numeric format
Performed exploratory data analysis using scatter plots and box plots
Trained a Linear Regression model
Evaluated the model using MAE and RMSE

📈 Key Insights
Smoking status has a significant impact on insurance charges
Higher BMI and age are associated with higher medical costs
The regression model provides a reasonable estimation of insurance charges
